# Design Context — Sona

**Product:** Sona — offline, on-device ambient medical scribe for Malaysian clinics.

**Target audience:** Malaysian private GP / family-medicine doctors (primary user). Time-pressed, work in English, multilingual patients. Patients are a secondary audience (visit summary, consent).

**Use cases:** Record a consult → auto SOAP note + paperwork (MC / referral / prescription / ICD-10) → doctor reviews, edits, e-signs → export (PDF / FHIR / push to clinic CMS). Runs fully offline. Understands code-switched ("rojak") speech. Privacy-first: PHI never leaves the device.

**Brand personality / tone:** Calm clinical confidence. Trustworthy, premium, warm, human. Quiet, not flashy — privacy and competence communicated through restraint. NOT generic medical-blue, NOT techy-dark-with-glow.

**Language policy:** UI chrome = **English-first** (doctors chart in English), with a Bahasa Melayu toggle. The *transcript* is rojak (BM + English + Mandarin + Tamil), color-coded by language — this is the headline feature. Notes output in English; patient summary is multilingual.

**Platform:** iOS-first (iPhone). Android on roadmap.

**Aesthetic direction — "Clinical Paper × Scrub Blue" (v3):** Heidi Health's warm, editorial, un-clinical base (cream paper, serif display, warm-brown shadows) — but with **DeepScribe's primary blue as the brand color** (user-chosen). Result: warm + trustworthy + confidently medical, never generic-healthtech-blue-on-white.
- **Neutrals (warm paper):** page bg `#f8f4ef` (warm cream, ≈ Heidi sand-50); surface/card `#fffdfa` (warm white, never pure #fff); ink/body `#1c1a17` (warm near-black, never pure #000); muted ink `#6f6860`; hairline border `#e7ddd0` (warm taupe).
- **Primary (DeepScribe scrub-blue):** `#126dec`; hover/pressed `#0f57bd`; deep `#0b3f8f`; tint bg `#e8f0fe`; faint wash `#f1f6fe`. Primary CTAs = blue pill buttons. Signature move = soft blue radial glow on the record hero (DeepScribe gradient) over warm paper.
- **Semantic:** verified/safe = forest green `#2b6c46`; low-confidence/warning = amber `#c07d18`; danger = clay-red `#c0362c`.
- **Language palette (rojak transcript, color-coded — the headline feature):** English = slate-blue `#2f6fb0`, BM = forest green `#2f7d4f`, Mandarin 中文 = clay-red `#c0392b`, Tamil = ochre `#b9740b`. (English distinct from brand `#126dec` so transcript ≠ chrome.)
- **Type:** Display = **Fraunces** (soft optical serif, Heidi's serif-on-cream signature), heading tracking very tight (-0.03 to -0.05em). Body/UI = **Hanken Grotesk** (refined grotesk, NOT Inter/Roboto). Technical labels/eyebrows/codes/timestamps/model-names = **IBM Plex Mono** (Heidi's mono-label signature), small + uppercase + tracked.
- **Form:** card radius 14–20px; pills for chips + buttons; warm-brown-tinted soft shadows `rgb(120 90 60 / .07–.10)` (NOT neutral grey drop shadows); generous asymmetric whitespace + hairline rules.
- **Avoid AI slop:** no cyan-on-dark, no purple gradients, no glassmorphism, no rounded-icon-above-every-heading, no neutral-grey drop shadows, no centered-everything.

**Showcase priority (the moat, must be visible in UI):** offline/airplane-mode · rojak code-switch transcript · privacy-by-architecture (data stays on device, de-identification) · doctor-in-the-loop safety (low-confidence flags, doses extracted-not-generated) · paperwork automation.

# Sona UI Refactor — editorial calm, kept clinical-green

Sona works end-to-end but reads like a dense tools screen: tight 4pt spacing, 10–16px type, heavy bordered cards, system font, and a leftover blue Better-T-Stack scaffold bolted next to the green consult flow. Heidi (the competitor we just catalogued in `heidi_ui_review.html`, 28 screens) reads like a calm editorial product: a **serif display headline**, generous whitespace, large type, soft rounded cards, a single bottom **CTA pill**, a floating **pill tab bar**, a big circular **record button**, and **bottom sheets** for settings/export.

**This plan adopts Heidi's spatial system and calm — and keeps green as the brand** (green = healthy, our clinical signal), swapping Heidi's maroon for our `#0e7c52` family. It also deletes the blue scaffold so there is one design system, not two.

**Decisions locked (this revision):** serif face = **Fraunces**; scope = **all 6 consult screens + a new Home in one pass**; **add** the Home/Consults list. The Home session list reads the existing SQLite `consults` table via a new `listConsults()` query in `lib/db`, seeded with 2–3 demo rows for the pitch and falling back to the locked demo consult when empty.

**Outcome:** the six consult screens + a new Home feel premium and unhurried, on a single green design system, with a serif display face, an 8pt scale, bottom-sheet patterns, and motion — no change to the on-device pipeline, security moat, or data flow.

## Heidi vs Sona — what we borrow (and what we don't)

| Dimension | Heidi | Sona today | Sona target |
|---|---|---|---|
| Headings | Serif display, large | System sans, 16px | **Serif display face** (Fraunces/Newsreader via expo-font), 26–34px |
| Background | Warm cream `#faf7f4` | Flat white `#fff` | Warm-neutral, faint green tint `#f8faf7` |
| Brand accent | Maroon `#4a2230` | Green `#0e7c52` | **Green `#0e7c52` kept** — deep `#0a5c3e` pressed |
| Spacing | Generous, ~8pt | Tight 4pt | **8pt scale**, roomier |
| Cards | Soft, ~20px radius, minimal border | 14px radius, hard 1px border | 18–20px radius, softer line |
| Primary action | One bottom pill | Bottom pill (ok) | Keep — larger, 16px label |
| Tabs | Floating pill bar | GlassTabBar (close) | Refine spacing/size |
| Record | Big circular mic + rings | Card w/ timer + waveform | **Big circular record button** |
| Pickers/actions | Bottom sheets | Inline cards / buttons | **Bottom sheets** (export, customise, session settings) |
| Toggles | Segmented (Transcribe/Dictate) | n/a | **Segmented control** on record |
| List rows | Avatar + title + time | n/a (no list) | New Home list rows |

**We do NOT borrow:** Heidi's maroon palette, its web-based sub-flows, or its density in settings. Our security surfaces (privacy gate, "0 bytes", audit) stay first-class — Heidi hides them; we lead with them.

## Design system — the green-first token overhaul

Everything lives in `lib/theme.ts` (single source; the blue `lib/constants.ts` scaffold is deleted). New/changed tokens:

**Typography (new).** Load **Fraunces** (chosen serif display) via `expo-font`; keep the system sans for body.
- `display` — Fraunces, 34/28/24px, weight 600, for screen titles + hero stats.
- `body` — system sans, 15/14px, lineHeight 1.5 (up from 11.5px).
- `label` — 11px uppercase, letterSpacing 0.08em, green — section labels.
- Font loaded via `expo-font` `useFonts` in `app/_layout.tsx` (currently unused — we wire it).

**Colour (kept green, warmed).**
- `paper #f8faf7` (was `#fff`), `card #ffffff`, `surface #eef4f0`.
- `green #0e7c52` (unchanged), `greenDeep #0a5c3e`, `greenSoft #e9f5ef`, `greenInk #0a3d2b`.
- `ink #0b1e16`, `ink2 #42534b`, `ink3 #5f6d64` (unchanged — already warm).
- Semantic red/amber/blue banks unchanged.

**Space (8pt).** `xs 4 · sm 8 · md 12 · lg 16 · xl 24 · xxl 32` (was 4/6/9/13/17/24).

**Radius.** `sm 12 · md 16 · lg 20 · xl 24 · pill 999` (was 10/14/20).

**Elevation.** Keep `glowShadow` green, soften to opacity 0.18 for cards; reserve the 0.28 glow for the primary CTA + record button only.

## Component plan — reuse first, then the new primitives

**Refactor (keep the API, restyle):**
- `ConsultScreen` — body padding 18/gap 16; title slot renders the serif display face.
- `Card` — radius 16–20, softer border, more padding; variants keep their colour banks.
- `PrimaryButton` — 16px label, 15–16px padding, radius 16; disabled/press states unchanged.
- `TopBar` — icon-only actions (customise/export/back) instead of text pills.
- `GlassTabBar` — reuse; retune spacing + size to the floating-pill proportion.
- `Stat` → scale to a serif hero on Complete.
- `Pill`, `Toggle`, `Waveform`, `DiarRow`, `RedactChip`, `SafetyNotice`, `Steps`, `LiveIndicators` — restyle via tokens, no API change.

**New primitives:**
- `BottomSheet` — grabber + spring-in; hosts export, customise-note, (future) session settings. `react-native-gesture-handler` already installed; add `react-native-reanimated` if not present for the spring.
- `SegmentedControl` — Transcribe / Dictate on the record screen.
- `RecordButton` — big circular button + pulsing rings (Reanimated), idle/recording/paused.
- `SerifTitle` — the display-face heading used across screens.
- `ListRow` + `SearchField` — for Home/Today, History, and Notes lists.
- `SettingsRow` — labelled setting rows (value + chevron / toggle) for the rebuilt Settings.

**Delete (the blue scaffold):** `lib/constants.ts` NAV_THEME usage, `components/container.tsx`, `components/header-button.tsx`, `components/tabbar-icon.tsx`, `app/(drawer)/(tabs)/*`, `app/modal.tsx` placeholders, and the drawer's Tabs entry. The drawer becomes: **Home (consults)** + **Consult demo** + **Spike bench** (dev-only).

## Motion

- **Record button**: two pulsing rings (scale + fade, Reanimated loop) while recording; spring on start/stop.
- **Bottom sheets**: spring translateY in, backdrop fade.
- **Screen titles**: subtle fade+rise on mount (120ms).
- **Tab bar**: active-tab colour/scale spring.
- **Waveform**: keep existing native-driver animation.
- Respect `prefers-reduced-motion` (skip pulses/rise).

## Implementation phases

1. **Tokens + fonts** — rewrite `lib/theme.ts` (type scale, 8pt space, radii, warmed paper), wire `useFonts` for the serif face in `app/_layout.tsx`, delete `lib/constants.ts` + blue scaffold. The app still builds; nothing visual ships until Phase 2 consumes it.
2. **Primitives** — restyle `ConsultScreen`/`Card`/`PrimaryButton`/`TopBar`/`Stat`/`Pill`; add `BottomSheet`, `SegmentedControl`, `RecordButton`, `SerifTitle`, `ListRow`, `SearchField`.
3. **Screens** — redesign consent → recording → privacy → note → sign → complete; build the **4 tab destinations** (Today, History, Notes, Settings); move export + customise into bottom sheets. Adds `listConsults()` + `listNotes()` queries over the existing SQLite tables (+ a 2–3 row demo seed); rows deep-link into the flow / a read-only note view.
4. **Motion** — record pulses, sheet springs, title rise, tab spring; reduced-motion guard.
5. **Device QA** — walk the flow on the physical iPhone (mobilecli), check type legibility, sheet gestures, record timing, light-only correctness; screenshot each.

**Hard-to-reverse bets to get right in Phase 1:** the type scale + serif face choice (touches every screen), the 8pt space/radius tokens (every component), and keeping `lib/theme.ts` the single source (deleting `constants.ts`). Cheap now, expensive after screens depend on them.

## Non-goals

- No change to the on-device pipeline, redaction, re-ID map, or "de-identified text only" moat.
- No dark theme (light-only stays — clinical + projector demos).
- No new data/persistence; screens keep reading the same SQLite + PipelineProvider state.
- Not a Heidi clone — green identity, security-forward, our consult flow.

### Decisions (locked)

- **Serif face → Fraunces.** Warm editorial display, loaded via `expo-font` `useFonts` in `app/_layout.tsx` (weights 400/600). System sans stays for body.
- **Scope → all 6 consult screens + new Home in one pass.** No spike; the full flow ships together so the demo is coherent end-to-end.
- **Home/Consults → added.** New route (top of the drawer / first tab). Session list = new `listConsults()` over the existing SQLite `consults` table, seeded with 2–3 demo rows; empty-state falls back to the locked demo consult. Rows push into the existing consult flow.

### Decision — Home tab bar (locked)

**Four real destinations, all wired** (no stubs):
- **Today** — active consult list (`listConsults()` over SQLite `consults`, today's rows).
- **History** — past/archived consults (same query, grouped by date; signed + complete).
- **Notes** — signed clinical notes (`listNotes()` over the `notes` table); tap → read-only note view.
- **Settings** — rebuilt in the green system: on-device status + model info, light-theme note, about/version. Replaces the deleted blue Better-T-Stack settings entirely.

All four reuse the same `ListRow` / `SearchField` / `SettingsRow` primitives + the floating tab bar, so the added scope is mostly data wiring, not new visual language.

Sona system context

Who uses Sona, through which app, and which outside systems the one server talks to. Staging only, with synthetic patients; no real hospital, lab or insurer is connected.

Who uses what

  • Staff roles: doctor, nurse, bed-manager, management; email + password
  • Patients sign in by phone OTP, Apple or Google and are linked to a record through care_links
  • Insurers get no account: claim.send makes a bearer link, 7 days, one decision; the Worker serves the review page
  • One Worker serves the API and both web portals, so the web shares the API's origin and cookies

Staging only

  • Synthetic patients: Demo General Hospital (synthetic), SYN- record numbers
  • No real lab, hospital system or insurer is connected
  • Patient OTP codes are only logged (no SMS provider)
  • Sona Care web has no /live socket; its screens poll

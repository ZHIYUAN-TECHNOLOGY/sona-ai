Sona deployment on staging

What runs where, and what is in Malaysia today. Stack sona-ai, stage staging only, with synthetic patients.

In Malaysia today

  • Every model host: five SageMaker endpoints and the sona-pii Lambda in ap-southeast-5
  • GPU endpoints are deleted between sessions (configs kept); with none up, model routes answer as labelled fixtures
  • sona-embed is always on; sona-live (MiniCPM-o) exists as code only, not deployed
  • Baseten configs remain the fallback host for any box not named in SAGEMAKER_ENDPOINTS

Not in Malaysia yet

  • Database: Neon in Singapore (region from the handoff, not in code)
  • Worker, Durable Objects and R2: Cloudflare, no jurisdiction or region pin in alchemy.run.ts
  • Pilot plan (pitch, not built): move the database and object storage into Malaysia
  • Also bound, not drawn: Workers AI (embedder fallback) and Email. No KV, Queues or Hyperdrive

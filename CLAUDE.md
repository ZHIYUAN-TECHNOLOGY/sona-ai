# Sona continuation

When continuing Sona work, read [the handoff](docs/handoff.md) first for the current milestone, verification boundary and next actions. Then read only the linked specifications relevant to the requested change.

The current milestone is a synthetic iPhone UI awaiting user review. Backend planning runs in parallel with UI review; leave `apps/native` UI files to the UI track. Preserve the existing working tree, including untracked feature files and documentation.

For any UI or UX work, in Sona or Sona Care, follow the [UX principles](docs/design-direction.md#ux-principles-standing-rules-for-every-screen) (insight first, action in place, meaningful highlights, review before deciding, suggested next steps, minimalism, built for hospital operations).
